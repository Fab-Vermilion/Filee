功能介绍

占位：介绍本服务用于文件类型转换，服务器端运行，经 WorkBuddy 自建菜单免登进入。开发定型后统一编写。

可转换类型

占位：列出支持的源格式与目标格式分类（图片/PDF/文档/表格/演示/文本/音视频/压缩包等）。实际以页面“可转换目标”为准。

使用方法

批量转换

占位：① 添加文件（可“继续添加”，单批最多 20 个）→ ② 系统检测格式，列出所有文件共同可转换的目标分类 → ③ 点击分类，选择目标格式 → ④ 开始转换 → ⑤ 在任务进度中逐个下载结果。

登录态失效

占位：401 时页面会请求客户端重新免登；未恢复可从菜单重新进入。

第三方协议

占位：列出所用外部引擎及其许可证（FFmpeg、Ghostscript、LibreOffice、ExifTool 等），具体条款开发定型后统一编写。
